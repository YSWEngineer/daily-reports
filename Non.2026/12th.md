## 💡 本日の学び・気付き
### 10.1 404 は「見つからない」というレスポンス
#### HTTPステータスコードを簡単に整理する
|ステータスコード   |意味   |具体例   |
|---|---|---|
|200 OK   |正常に処理できた   |映画の詳細画面を表示できた   |
|303 See Other   |別の URL へ移動するよう指示   |登録・更新・削除後のリダイレクト   |
|404 Not Found   |要求されたものが見つからない   |存在しない映画ID   |
|500 Internal Server   |サーバー内部で予測しないエラーが発生   |Ruby のプログラムで例外が発生   |

#### 404 Not Found とは？
`404 Not Found`は、リクエストされたリソースが見つからないことを表すステータスコード。
たとえば、映画図鑑で次の URL にアクセスしたとする。
```text
http://localhost:4567/movies/not-found
```
この URL は、映画の詳細画面を表示するルートと一致する。
しかし、`not-found`という ID の映画は JSONファイルに存在しない。
その場合、アプリケーションは`404`を返す必要がある。

#### なぜ 404 を知らせる必要があるのか？
存在しない映画の詳細画面を要求したのに、正常な画面として表示されてしまったら、利用者は「映画の情報が空なのかな？」「読み込みに失敗したのでは？」と混乱してしまう。
そこで、`404`をちゃんと返すことで、**「あなたが要求した映画は存在しませんよ」**ということで、ブラウザや利用者に正しく伝える。

#### 第6章の halt は？
映画図鑑にはすでに`404`を返す処理が実装されている。
```ruby
halt 404, "映画が見つかりません" if @movie.nil?
```
|コード   |役割   |
|---|---|
|halt   |その場で処理を終了する   |
|404   |HTTPステータスコードを404にする   |
|"映画が見つかりません"   |レスポンスとして返すメッセージの内容   |
|@movie.nil?   |映画が見つからなかったかを確認する   |

### 10.3 存在しない映画ID を確認する

### 10.4 404 と 500 の違い
|ステータスコード   |意味   |
|---|---|
|404 Not Found   |要求されたものが見つからない   |
|500 Internal Server Error   |サーバー内部で予測しないエラーが発生した   |

#### 500 を発生させるコードを入力する
`500`エラーを表示させるために以下のコードを入力し、確認する。
```ruby
get "/error-example" do
  raise "確認用のエラー"
end
```
|コード   |役割   |
|---|---|
|get "/error-example"  |/error-example に GET でアクセスしたときの処理を定義する   |
|raise   |意図的に例外を発生させる   |
|"確認用のエラー"   |エラーの内容を示すメッセージ   |
|end   |ルートの処理を終了する   |

#### 404 と 500 の違い
|404   |500   |
|---|---|
|要求されたものが見つからない   |サーバー内部で予期しないエラーが発生   |
|存在しない URL や映画ID   |プログラムの例外など   |
|halt 404 などで返す   |今回は raise によって発生   |

### 考えてみよう
**① なぜ見つからない映画 ID を空の詳細画面として表示しないのでしょうか。**
回答：映画が存在しないのにからの詳細画面を表示すると、利用者は「映画の情報が空なのかな？」「読み込みに失敗したのかな？」と混乱してしまうから。そのため、映画が見つからない場合は`404`を返し、存在しないことを明確に伝える。

**② 404 と 500 は、どちらもエラーに見えますが、何が違うのでしょうか。**
回答：エラーが発生した理由が違う。
- `404 Not Found`：指定された URL や映画ID に該当するものが見つからない。
- `500 Internal Server Error`：プログラムの不具合などによって、サーバー内部で正常に処理できなかった。

**③ 画面にエラーメッセージが出ていても、Network パネルでステータスコードを見る必要があるのはなぜでしょうか。**
回答：画面に表示されるエラーメッセージだけでは、サーバーが正しいステータスコードを返しているか分からないから。たとえば、画面には「映画が見つかりません」と表示されていても、HTTPステータスコードが`200`（正常）になっている可能性がある。
Networkパネルを確認すれば、サーバーが実際に`400`や`500`を返しているか判断できる。
