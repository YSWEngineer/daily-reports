## 💡 本日の学び・気付き
### 3.1 HTML を含む文字列を返す
指示の通りに操作してみると、
- ブラウザの表示：HTMLが認識され、画面には h1 の見出しで「映画図鑑」が表示された。
- Network の Response：サーバーが返したレスポンス本文には、`<h1>映画図鑑</h1>`という HTML が含まれていた。

つまり、**ブラウザは Ruby のコードそのものではなく、Ruby の処理によって返された HTML を解釈し画面に表示**されている。
