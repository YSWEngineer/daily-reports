タイトル・監督・公開年・ジャンル・紹介文

**②** `POST /movies`
ブラウザが入力値をリクエストとして送る
　　　↓
Sinatra がリクエストを受け取る
**③ params で入力値を取り出す**
送信されたキーと値を確認する

確認用のレスポンスを返す

### 4.1 登録画面 GET /movies/new
#### なぜ、説明文の下にリンクを追加するのか？
現在の HTML は、ページを開いた人に次の順番で情報を見せている。
1. 映画一覧という見出し
2. 映画一覧についての説明
3. 登録されている映画の一覧

ここに新しい映画を登録するためのリンクを加えると、**説明文を読んだあとに、映画を登録する画面へ進める**ようになるから、と推測。

#### 3つの要素の役割を比較する
|HTML要素   |主な役割   |
|---|---|
|aタグ   |リンクを作り、別のページなどへ移動する   |
|formタグ   |入力フォームを作り、入力したデータを送信する   |
|tableタグ   |表形式でデータを表示する   |

4.1 では、映画一覧ページから映画の登録画面へ移動するため、`<a>`要素を使う。

#### 復習：aタグの仕組み
```html
<a href="/movies/new">新しい映画を登録</a>
```
- `<a>`：リンクを作る要素。
- `href="/movies/new"`：リンク先のパスを指定する。
- `新しい映画を登録`：ブラウザ上でリンクとして表示される文字。
- `</a>`：要素の終わり。

つまり、このリンクをクリックすると、ブラウザは`/movies/new`というパスにアクセスする。

#### 今回の処理の流れ
**映画一覧ページ**
`views/index.erb`
　　　↓
**「新しい映画を登録」をクリック**
`<a href="/movies/new">`
　　　↓
**GET /movies/new**
ブラウザから Sinatra へリクエスト
　　　↓
**映画登録画面を返す**
ルートで`erb :new`を実行

#### リンクを追加しただけでは、登録画面を表示できない
`views/index.erb`ファイルに、指定されたリンクを追加しただけでは登録画面は表示できない。
なぜなら、Sinatra側にそのリクエストを処理するルートがないため、ページを表示できないから。

#### GET /movies/new のルートを追加する
現在の`app.rb`ファイルで確認した主な記述は、次のとおり。
|記述   |役割   |
|---|---|
|get "/"   |トップページへのリクエストを処理する   |
|get "/movies"   |映画一覧ページへのリクエストを処理する   |
|redirect "/movies"   |/ へのアクセスを /movies へ転送する   |
|erb :index   |views/index.erb を使って HTML を生成する   |

今回、新しく作るのは映画の登録画面を表示するルート。
```ruby
get "/movies/new" do 
  erb :new
end
```
- `get "/movies/new"`：ブラウザから`GET /movies/new`というリクエストが届いた時に実行する処理を定義している。
- `erb :new`：`views/new.erb`をテンプレートとして使い、HTML を生成してレスポンスとして返す。

#### views/new.erb を作成する
まず、`views`ディレクトリにファイルが作られているか確認する。
```zsh
~/sinatra-movies % ls views
index.erb	layout.erb
```
現時点では`index.erb`と`layout.erb`が表示される。
まだ`new.erb`がないことを確認できたので、Vim で新しいファイルを開き、指定された2つの要素を書き込む。
```zsh
~/sinatra-movies % vim views/new.erb
```
```html
<h1>映画登録</h1>

<p>登録したい映画の情報を入力します。</p>
```

### 4.2 form の action と method
- フォームは、ブラウザに HTTPリクエストを作らせるための HTML。

#### リンクとフォームの違いを整理する
|要素   |目的   |今回の映画図鑑アプリでの例   |
|---|---|---|
|a   |別のページへ移動する   |映画登録画面を開く   |
|form   |入力したデータを送信する   |映画の情報をサーバーへ送る   |

リンクは画面を移動するためのもの、フォームはデータを送信するためのもの。

#### action と method を理解する
`form`の2つの属性について。
```html
<form action="/movies" method="post">
```
|属性   |意味   |
|---|---|
|action="/movies"   |フォームのデータを送信する先を指定する   |
|method="post"   |データを送信する時に使う HTTPメソッドを指定する   |

この2つの属性によって、フォームの送信先と HTTPメソッドが決まる。
HTML では、`method="post"`と小文字で`post`が書かれている。
HTTPメソッドでは、`POST`と大文字で書く。

### 4.3 name が params のキーになる
#### 3つの属性を見比べる
これから追加するフォーム部分には、次の記述がある。
```html
<label for="title">タイトル</label>
<input type="text" id="title" name="title">
```
|属性   |役割   |
|---|---|
|for="title"   |ラベルと、対応する入力欄を結び付ける   |
|id="title"   |HTML内で入力欄を識別するための ID   |
|name="title"   |フォーム送信時に、入力値を識別するための名前   |

`name="title"`と指定すると、フォームの送信データでは`title`が項目名になる。
Sinatra側では、`params["title"]`を使って、その項目に対応する値を取得できる。
具体的な受け取り方は、4.5 で確認する。
