### 6.1 /movies は映画の集合を表す
#### コードの処理の流れを確認する
```ruby
get "/movies" do
  @movies = load_movies
  erb :index
end
```
この処理は次の順番で実行される。
1. `load_movies`を呼び出す。
2. `data/movies.json`から映画データを読み込む。
3. JSON形式のデータを Ruby の配列・ハッシュに変換する。
4. 読み込んだデータを`@movies`に代入する。
5. `erb :index`で一覧画面を表示する。

`@movies`はインスタンス変数で、Sinatra のルートで用意したデータを ERBテンプレートから参照できるようにする。
つまり、
**app.rbファイルでデータを用意する → ERBに渡す → HTML として表示する**
という関係。

#### /movies が表すリソースについて
第6章では、映画の一覧画面と詳細画面を分けて作っていく。
まず、現在の`/movies`は映画 1件ではなく、登録されている映画の集合を表す URL であることを確認した。
また、一覧画面にはタイトル・公開年・ジャンルを表示し、監督や紹介文の詳しい情報は詳細画面で確認できるようにする。
画面ごとに表示する情報を分けることで一覧の見易さと情報の整理に繋がると理解した。
|URL   |表すもの   |
|---|---|
|/movies   |映画の集合   |
|/movies/:id   |ID で指定された映画 1件   |


#### 学習のポイント
- `/movies`は映画の集合を表す。
- `@movies`には複数の映画データが入る。
- 一覧画面と詳細画面では、表示する情報の役割が異なる。

### 6.2 /movies/:id は 1件の映画を表す
#### コードの意味を確認する
```ruby
get "/movies/:id" do
  h(params["id"])
end
```
|コード   |役割   |
|---|---|
|get   |GETリクエストを受け取る   |
|"/movies/:id"   |映画の ID を含む URL に対応する   |
|params["id"]   |URL から受け取った ID を取得する   |
|h(...)   |HTMLエスケープを行う   |

たとえば、次の URL にアクセスしたとする。
```text
/movies/b6f5e1c4-4b5f-4a7f-8f8f-3d9d3ef9d001
```
この場合、
```ruby
params["id"]
```
で取得できる値は、
```text
b6f5e1c4-4b5f-4a7f-8f8f-3d9d3ef9d001
```
である。
つまり、URL に含まれている ID を Sinatra が受け取り、Ruby の処理で利用できるようにしてくれる。

**ブラウザからアクセス**
`/movies/b6f5e1c4-4b5f-4a7f-8f8f-3d9d3ef9d001`
　　　↓
**Sinatra のルート**
`get "/movies/:id"`
　　　↓
**params["id"]**
URL から映画の ID を取り出す

#### リソースとは？
**リソース**とは、Web で URL を使って指し示し、扱う対象のこと。
今回の映画図鑑では、映画がリソースである。
- `/movies`：映画の集合というリソース。
- `/movies/:id`：個別の映画というリソース。

#### ルートパラメーター
URL の中にある変化する部分を、ルートパラメーターとして扱う。
今回の`:id`がそれに当たる。
似た仕組みは第4章にも登場していた。
|第4章   |第6章   |
|---|---|
|name="title"   |:id   |
|params["title"]   |params["id"]   |
|フォームから値を受け取る   |URL から値を受け取る   |

どちらも最終的には`params`を使用して値を取得するが、値の場所が違う。
第4章では**フォーム**、第6章では**URL**。

#### /movies/:id が表すリソースについて
この節では、映画の集合を表す`/movies`に対して、映画 1件を表す`/movies/:id`について学んだ。
`:id`は実際の映画に ID に置き換わる部分であり、Sinatra では`params["id"]`を使って URL から値を取得できる。
また、`/movies/new`のような具体的なルートより後に、`:id`を含むルートを配置する必要があることも学んだ。
